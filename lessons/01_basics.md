# Lesson 1: Basics / Lección 1: Fundamentos

Goals: variables, types, functions, running code, and tests.

> **ES:** Objetivos: variables, tipos, funciones, ejecutar código y pruebas (tests).

1. Run the example: `uv run python -m larry.hello`
2. Read `src/larry/hello.py` and `tests/test_hello.py`.
3. Exercise: add `farewell(name)` to `hello.py` and write a test for it first.
4. Check your work: `uv run pytest`

> **ES:**
> 1. Ejecuta el ejemplo: `uv run python -m larry.hello`
> 2. Lee `src/larry/hello.py` y `tests/test_hello.py`.
> 3. Ejercicio: agrega `farewell(name)` a `hello.py` y escribe primero una prueba para esa función.
> 4. Revisa tu trabajo: `uv run pytest`

Type hints (`name: str`) are checked by `uv run ty check`.

> **ES:** Las anotaciones de tipo (`name: str`) se verifican con `uv run ty check`.
