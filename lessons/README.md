# Syllabus / Temario

> **ES:** Cada lección tiene su guía aquí (inglés y español lado a lado), un ejercicio en `exercises/NN_tema/` y una solución en `solutions/NN_tema/`. Hazlas en orden y revisa `solutions/` solo después de intentarlo.

Each lesson has a guide here, a stub in `exercises/NN_topic/`, and a reference
solution in `solutions/NN_topic/`. Work the lessons in order:

```sh
uv run pytest exercises/02_control_flow   # fails until you implement the stubs
```

Peek at `solutions/` only after a real attempt.
